# Can I Walk My Dog Today? - Web Application

This is the web application for the "Can I Walk My Dog Today?" project. It's built with Next.js 15, React 19, and Tailwind CSS 4.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Check weather conditions for dog walking safety
- Personalize recommendations based on dog size and preferences
- View forecasts for upcoming days

## Technologies Used

- Next.js 15.4.1
- React 19.0.0
- TypeScript 5.4+
- Tailwind CSS 4.1.10
- TanStack Query 5.0+
- Edge Runtime for API routes
